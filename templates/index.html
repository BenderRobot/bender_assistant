    Installer le modèle Vosk français manquant

    Dans le terminal SSH sur Debian, depuis le dossier de l’application :

    cd ~/applications/bender_assistant
.venv/bin/python -m bender_voice --config voice.json download-models vosk

    Puis clique sur « Actualiser le diagnostic ». La transcription est locale ; l’envoi au cerveau GPT demande Internet. Pour tester uniquement le micro, décoche l’envoi au cerveau.

    Cerveau GPT · compte ChatGPT

    Vosk transcrit le micro en local. GPT prépare la réponse via Internet, puis ta chaîne de voix anime la bouche. Cette connexion utilise les limites de ton forfait ChatGPT ; aucune clé API facturée séparément n’est utilisée.

    Vérification de la connexion ChatGPT.

    Continuer avec ChatGPT / Continue with ChatGPT

    Après la mise à jour du Debian, lance ce script dans PowerShell sur ton PC. Il ouvre le tunnel SSH de connexion et affiche le lien officiel à ouvrir dans ton navigateur. Connecte-toi et autorise Bender Jarvis ; la page de retour confirmera l’enregistrement.

    powershell -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\Documents\bender_main\CONNECTER_CHATGPT.ps1"

    Garde le terminal ouvert pendant la connexion, puis clique sur « Actualiser le statut ». Ton mot de passe ChatGPT reste sur la page officielle d’OpenAI. Les autorisations sont stockées sur le Debian.

    Pour ajouter un autre compte ou espace : relance le script avec -NewAccount. Pour reconnecter un compte existant, choisis-le ci-dessous avant de relancer le script.

    Caméra et vision

    La photo est prise par la LifeCam du Dell. Elle est envoyée à GPT uniquement avec le bouton d’analyse.

    Chaque photo laisse deux secondes à l’exposition pour se stabiliser. La capture utilise le mode HD 1280 × 720 si la LifeCam le propose.

    Qualité d’image et exposition

    Si les blancs sont brûlés, clique sur « Charger les réglages », puis « Moins exposée ». Chaque modification prend une nouvelle photo sans l’envoyer à GPT. « Automatique » rétablit l’exposition et la balance des blancs automatiques, ainsi que la luminosité et le contraste d’usine disponibles.

    Les réglages disponibles dépendent du pilote de la caméra.

    Une zone entièrement blanche sur une ancienne photo ne peut pas retrouver ses détails : il faut réduire l’exposition et prendre une nouvelle image.

    La correction automatique de luminosité, contraste et netteté est appliquée à chaque photo avant l’analyse GPT. L’original est conservé ; les zones déjà brûlées ne retrouvent pas leurs détails.
